# 部署指南

从一台空白的 Linux 机器，到机器人能回消息。全程约 40 分钟。

---

## 0. 机器要求

| 项 | 最低 | 推荐 |
|---|---|---|
| CPU | 1 核 | 2 核 |
| 内存 | 2 GB | 4 GB |
| 磁盘 | 20 GB | 40 GB |
| 系统 | Ubuntu 22.04 / Debian 12 | 同左 |
| 网络 | 能访问外网 | 国内机器建议能连 GitHub |

> **重要**：2GB 是下限，不是舒适区。详见 [避坑.md](./避坑.md) 第 4 条。

---

## 1. 基础环境

### 装 Docker

```bash
curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
docker --version    # 确认装好
```

### 装 Node.js 18+

```bash
curl -fsSL https://deb.nodesource.com/setup_18.x | bash -
apt install -y nodejs
node -v             # 应该是 v18 或更高
```

### 加 swap（2G 机器必做）

```bash
fallocate -l 4G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab

# 降低换出倾向，让热数据尽量留在内存
echo 'vm.swappiness=10' >> /etc/sysctl.conf
sysctl -p
```

### 清理无用服务（省内存）

```bash
systemctl disable --now fwupd multipathd
systemctl disable --now snapd 2>/dev/null
```

## 2. 部署中转站

```bash
mkdir -p /root/relay && cd /root/relay

git clone https://github.com/ZhengWill/dafeiyu.git tmp
cp tmp/relay/relay.mjs .
cp -r tmp/relay/ui .
cp tmp/relay/relay.example.json relay.json

nano relay.json    # 按下面说明填
```

### 配置要点

**最少改这三处：**

```jsonc
{
  "apiKey": "自己生成一串随机字符",     // openssl rand -hex 24
  "exposeModel": "dafeiyu",            // 客户端认的名字，随便叫
  "providers": [ /* 至少一个真实供应商 */ ]
}
```

**供应商怎么填：**

```jsonc
{
  "id": "my-provider",           // 唯一标识
  "label": "我的供应商",          // 显示名
  "api": "openai",               // openai | anthropic
  "base": "https://api.xxx.com/v1",
  "key": "sk-真实key",
  "enabled": true,
  "models": [
    { "id": "deepseek-chat", "enabled": true, "contextWindow": 65536 }
  ]
}
```

**然后把它加进链：**

```jsonc
"chain": [
  { "providerId": "my-provider", "modelId": "deepseek-chat", "enabled": true }
]
```

> `providerId` 填供应商的 `id`，`modelId` 填模型的 `id`。

### 试跑

```bash
node relay.mjs
```

看到这行就对了：

```
[relay] listening on 0.0.0.0:8790
```

**浏览器打开 `http://你的IP:8790/`** —— 应该能看到管理面板。
如果没配 `apiKey`，终端会打印一个自动生成的 key，把它记下来。

### 配成系统服务

```bash
mkdir -p /root/.config/systemd/user

cat > /root/.config/systemd/user/relay.service <<'EOF'
[Unit]
Description=Dafeiyu Relay
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/relay
ExecStart=/usr/bin/node /root/relay/relay.mjs
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now relay
systemctl --user status relay
```

**让用户服务在未登录时也跑：**

```bash
loginctl enable-linger root
```

## 3. 部署 QQ 协议端

```bash
docker run -d \
  --name snowluma \
  --restart unless-stopped \
  -p 5099:5099 \
  -p 6081:6081 \
  -p 3000:3000 \
  -v qq-client-config:/app/.config \
  -v qq-gateway-data:/app/data \
  -v qq-client-data:/app/.local/share \
  motricseven7/snowluma:latest
```

**扫码登录：**

浏览器打开 `http://你的IP:5099`，用要当机器人的 QQ 号扫码。

> 建议用小号。协议端有封号风险，详见 README 的合规提醒。

**拿到 OneBot 连接信息：**

登录后在 SnowLuma 面板里找到 OneBot v11 HTTP/WS 服务，记下：
- 地址（通常是 `http://你的IP:3000`）
- Access Token（如果有）

## 4. 部署 AstrBot

```bash
mkdir -p /root/bot/astrbot/data

docker run -d \
  --name astrbot \
  --restart unless-stopped \
  -p 6185:6185 \
  -v /root/bot/astrbot/data:/AstrBot/data \
  soulter/astrbot:latest
```

浏览器打开 `http://你的IP:6185`，默认账号密码见 AstrBot 文档（通常是 `astrbot` / `astrbot`）。

### 4.1 接入 QQ

AstrBot 面板 → **平台适配器 → 新增 → aiocqhttp**

| 字段 | 填什么 |
|---|---|
| 名称 | 随便，比如 `my-qq` |
| 反向 WS 地址 | 留空或按 SnowLuma 提示填 |
| Host | SnowLuma 的地址 |
| Port | `3000` |
| Access Token | SnowLuma 里那个 |

保存后回到 SnowLuma 看是否显示「已连接」。

### 4.2 接入模型

AstrBot 面板 → **服务提供商 → 新增 → OpenAI 兼容**

| 字段 | 填什么 |
|---|---|
| 名称 | `中转站` |
| API Base | `http://你的IP:8790/v1` |
| API Key | 中转站的 `apiKey` |
| 模型 | 中转站的 `exposeModel`（如 `dafeiyu`） |

### 4.3 测试

在 AstrBot 面板的「对话」页发一句「你好」。有回复就通了。

## 5. 部署控制台（可选）

```bash
mkdir -p /root/dashboard && cd /root/dashboard
cp /root/relay/tmp/dashboard/server.mjs .
cp /root/relay/tmp/dashboard/index.html .
```

**必须设密码**，否则登录会被拒绝：

```bash
cat > /root/.config/systemd/user/dashboard.service <<'EOF'
[Unit]
Description=Dafeiyu Dashboard
After=network.target

[Service]
Type=simple
WorkingDirectory=/root/dashboard
Environment="DASH_USER=admin"
Environment="DASH_PASS=改成你的密码"
Environment="SL_PASSWORD=SnowLuma的WebUI密码"
Environment="SL_PUBLIC_HOST=你的服务器IP"
Environment="SL_VNC_PASS=noVNC密码"
Environment="WB_PROXY_KEY=如果用WorkBuddy才需要"
ExecStart=/usr/bin/node /root/dashboard/server.mjs
Restart=always
RestartSec=5

[Install]
WantedBy=default.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now dashboard
```

打开 `http://你的IP:8080` 登录。

## 6. 配置自动备份（强烈建议）

### 6.1 建一个私有仓库

在 GitHub 上建一个 **private** 仓库，比如 `my-bot-backup`。

### 6.2 生成 token

GitHub → Settings → Developer settings → Personal access tokens → **Fine-grained token**

权限只勾：**Contents: Read and write**，仓库范围只选刚才那个备份仓库。

### 6.3 配置脚本

```bash
cd /root
cp /root/relay/tmp/backup/backup.sh .
cp /root/relay/tmp/backup/push_backup.py .
chmod +x backup.sh

# token 存文件，权限 600
echo 'ghp_你的token' > /root/.ghtoken
chmod 600 /root/.ghtoken
```

**改备份脚本里的路径**（默认是 `/root/...`，路径不同要改）。

### 6.4 配定时任务

```bash
cat > /root/backup-daily.sh <<'EOF'
#!/bin/bash
set -e
export GITHUB_TOKEN=$(cat /root/.ghtoken)
export GITHUB_OWNER=你的GitHub用户名
export GITHUB_REPO=my-bot-backup
cd /root
./backup.sh
python3 push_backup.py
EOF
chmod +x /root/backup-daily.sh
```

```bash
cat > /root/.config/systemd/user/dafeiyu-backup.service <<'EOF'
[Unit]
Description=Dafeiyu Backup

[Service]
Type=oneshot
ExecStart=/root/backup-daily.sh
EOF

cat > /root/.config/systemd/user/dafeiyu-backup.timer <<'EOF'
[Unit]
Description=Daily backup timer

[Timer]
OnCalendar=*-*-* 04:20:00
RandomizedDelaySec=2400
Persistent=true

[Install]
WantedBy=timers.target
EOF

systemctl --user daemon-reload
systemctl --user enable --now dafeiyu-backup.timer
```

**手动验证一次：**

```bash
systemctl --user start dafeiyu-backup.service
journalctl --user -u dafeiyu-backup -n 30
```

去 GitHub 仓库确认文件传上去了。

## 7. 验收清单

逐条过一遍，都通过才算部署完成：

- [ ] `curl http://127.0.0.1:8790/health` 返回正常
- [ ] 用 curl 调 `/v1/chat/completions` 能拿到回复
- [ ] 中转站管理面板能打开、能看到降级链
- [ ] SnowLuma 面板显示 QQ 在线
- [ ] AstrBot 面板显示平台已连接
- [ ] 用另一个 QQ 给机器人发消息，能收到回复
- [ ] 重启服务器后，所有服务自动起来（`systemctl --user is-enabled` 都是 enabled）
- [ ] 备份能跑通，GitHub 上有文件

## 8. 日常维护

**看服务状态：**

```bash
systemctl --user status relay
docker ps
```

**看日志：**

```bash
journalctl --user -u relay -f          # 中转站
docker logs -f astrbot                 # Bot
docker logs -f snowluma                # 协议端
```

**重启某个服务：**

```bash
systemctl --user restart relay
docker restart astrbot
```

**加一个供应商：**

不用改文件，直接在中转站面板的「供应商」Tab 里点「添加」。加完去「模型」Tab 勾选启用，再去「降级链」Tab 拖进链里。

**服务器被回收了怎么办：**

```bash
# 在新机器上
export GITHUB_TOKEN=你的token
export GITHUB_OWNER=你的用户名
export GITHUB_REPO=my-bot-backup
bash restore.sh
```

然后按脚本最后打印的手动步骤补齐（主要是重新扫码登录 QQ）。
