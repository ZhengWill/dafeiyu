# AstrBot 插件集

自己写的三个 AstrBot 插件，都是**在真实群里跑了几个月**磨出来的。

| 插件 | 作用 | 说明 |
|---|---|---|
| [**yu_wake**](./astrbot_plugin_yu_wake/) | 唤醒 + 连续对话 + 主动发言 + 防封控 | 主插件，679 行 |
| [**auto_accept**](./astrbot_plugin_auto_accept/) | 自动通过好友/群邀请并欢迎 | 小工具，84 行 |
| [**poke_debug**](./astrbot_plugin_poke_debug/) | 事件调试（把所有入站事件打日志） | 排查用，36 行 |

另有一份 [**meme_manager 改动说明**](./meme_manager-patches/) ——
不是我们的插件，是对 [anka 的插件](https://github.com/anka-afk/astrbot_plugin_meme_manager)
（MIT）做的本地修改记录。**只记改动，不含源码**。

---

## 为什么写这些

AstrBot 本身是个很好的框架，但它默认是**被动响应式**的：@ 才说话，说完就消失。

放到 QQ 群里，这种表现有几个硬伤：

- 群友喊名字但没 @ → 机器人当没看见
- 聊两句又得重新 @ → 像在跟客服说话
- 从不主动说话 → 像个开关
- 一接话就每句都回 → 刷屏
- 被戳一拍完全无视

`yu_wake` 就是逐条解决这些。详见它的 [README](./astrbot_plugin_yu_wake/README.md)。

## 快速安装

```bash
# 进 AstrBot 插件目录
cd /你的路径/astrbot/data/plugins

# 复制需要的插件
cp -r /path/to/plugins/astrbot_plugin_yu_wake .

# 重启
docker restart astrbot
```

**必做配置**：设置主人 QQ 号（`yu_wake` 用它判断谁能用管理指令）

```bash
# 环境变量方式（推荐）
docker run -e OWNER_QQ=你的QQ号 ...
```

或直接改 `main.py` 里的 `os.environ.get("OWNER_QQ", "")`。

## 三个插件的定位

### yu_wake —— 主力

这个插件承载了「让机器人像群里的一员」的全部逻辑：

- **分层唤醒**：唯一称呼必回，高频词要看语境
- **会话 TTL**：叫醒后 5 分钟内不用再点名
- **主动发言 + 四重节流**：仿真人节奏（总量低但会连发）
- **戳一戳必回**：私聊回戳，群聊只回文字（协议限制）

外加 `#白饭`、`#群分析` 等指令。

### auto_accept —— 省事

有人加好友或邀请进群，自动通过并说句欢迎。纯自动化，无交互逻辑。

**注意**：如果你不想随便通过申请，别装这个。

### poke_debug —— 排查

把收到的每条事件的完整结构打到日志里。

**用途**：当你不确定某个事件（戳一戳、群邀请、撤回）在 AstrBot 里长什么样时，
装上它，操作一次，看日志，就知道字段名和类型了。

**日常不用开**，日志会很吵。

## 设计理念

写这三个插件的过程中，有几条是反复验证过的：

**1. 宁可漏掉，不要乱插话**

一个在群里乱接话的机器人，比一个安静的机器人更让人烦。
所以弱唤醒词全部要过语境检查。

**2. 节流比伪装重要**

想不被封，与其改 UA、改协议，不如**让节奏真的像人**：
总量低、允许连发、有沉默期。

**3. 注释写「为什么」，不写「是什么」**

`self.max_per_10min = 8` 旁边写的是
「它 17 分钟 10 条，这里 10 分钟 8 条」——
这是观察依据，不是废话。

**4. 承认限制**

群聊发不出 poke 就说发不出，不硬要绕。
协议限制写清楚，比假装没有强。

## 已知限制

| 限制 | 说明 |
|---|---|
| 群聊不能回戳 | OneBot 协议限制，`poke` 消息段仅私聊可用 |
| 依赖 AstrBot API | 大版本升级可能需要适配 |
| 群号需手动配 | 没有自动发现 |
| `#白饭` 依赖中转站 | 不用中转站则该指令无效（不影响其余功能） |

**防封控的诚实说明**：这些插件能去掉明显的机器特征，但不是免死金牌。
QQ 协议端本质是协议模拟，腾讯有风控。**建议只挂小号。**
